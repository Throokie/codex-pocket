# 安全与支持边界

这是个人自托管的非官方客户端，所有配对设备均按站主本人设备信任，尚未实现朋友/多租户权限隔离。请勿向他人分享设备或管理凭据。

- 手机API与本机管理使用不同监听和路由表，管理口固定回环且仍校验独立能力凭据与Origin；反代只指向API口，不能指向管理口。不使用转发IP判断管理身份。
- 二维码是短期一次性秘密。扫码消费票据但不授权，必须在电脑核对短语并批准。设备token独立、DB存哈希；仅配对领取阶段保留120秒加密信封，以恢复丢失回执。配对取消、新服务和旧网络响应使用代次隔离。
- 正式手机连接要求HTTPS。当前开发APK仅额外允许数字形式本机/可信局域网HTTP，传输未加密；不要在不可信Wi-Fi使用该方式。反代TLS只保护手机到代理的链路，不提供端到端对抗服务器/反代的加密承诺。
- Android凭据由Keystore保护的AES-GCM加密保存，不进入网页localStorage或JS响应。App关闭文件访问，仅打包资源origin可使用原生桥，外链由系统浏览器处理。
- 桌面通过同用户Unix IPC跟随；它不是额外操作系统隔离。同用户恶意进程仍可能访问本人桌面。桥不复制Codex登录凭据、不读写会话数据库或rollout、不启动第二执行所有者。
- 原生接口是当前已装桌面的内部协议，可能随升级变化。握手/版本/owner不匹配时断开或只读降级，不改桌面应用、不降低原审批策略。
- 原生答案只回原始请求。命令有实际内容时显示选项；缺少可审查差异的文件修改、MCP/额外权限及敏感提问回电脑处理。不存在的选项不拼造。用户在手机明确操作才回传，不自动审批或续跑。
- 写动作在获得串行锁后重验设备和controller_id，再预留去重账目。未知不重放，桌面接受也不等于业务完成。设备撤销关闭事件连接，尚未派发的排队写入不得继续。
- 图片限制15MB及4000万像素，重编码为静态JPEG/PNG去元数据；动图首帧处理。图片总缓存约250MB到限拒绝，不无限占盘。回传图片来自显式媒体根白名单；不接受远端URL和客户端文件路径。默认不开放用户整个home作为媒体根。
- 只保留少量总控可见消息；本机桥不会把完整原生快照、推理和任意工具输出存入手机。待处理请求和投递账目不随聊天缓存清理。去重账目现不自动淘汰，长期需备份/维护，不以过早删除换取去重失效。
- API、CLI和管理页不得打印token、二维码payload、消息正文或原图。默认关闭HTTP访问日志；运行目录权限700、秘密文件600。发布包明确排除运行数据、签名私钥和本机配置。

系统回收/后台限制会影响连接服务。App提供可见的后台连接服务，不宣称强杀进程或网络不可达时仍能推送。本版没有依赖Google FCM，适合先在本人手机验证通知和省电设置；系统限制不能靠客户端代码承诺消除。

## 多线路补充（0.2.0）

二维码信任服务P256公钥与明确候选origin，服务仅为电脑管理员登记的origin出具随机nonce+origin绑定签名。候选检测不带Bearer，正常HTTPS校验与禁止重定向仍是通道安全前提。签名不能防明文实时relay。自动配置有HTTPS时不降HTTP；release只HTTPS；debug私网HTTP属于显式开发信任。手机手动添加任意地址不等于该地址已获凭据。多地址仅同实例同数据库，非复制key后的多主。线路变化不自动重放写入，不变更配对身份。

## 自动发现与私网 TLS（0.3.0）

新二维码在原有服务 P256 身份之外，明确授权自动发现并固定该服务 TLS 公钥的 DER SPKI SHA256。私网自动地址使用此 pin 验证 TLS；它不是关闭证书检查，也不会信任局域网中任意自签证书。手动公网地址继续使用系统 TLS 校验。服务身份密钥和 TLS 私钥均留在服务运行目录，不进入源码包；更换身份或 TLS 公钥需要重新建立信任，证书续期保留同一公钥。

电脑只读取本机受支持的局域网接口和本机 Tailscale 状态，不扫描子网、不枚举 Tailscale peers、不安装或开启 VPN。mDNS/Android NSD 仅提供寻找已配对电脑的线索，服务名、TXT、IP 和端口均不构成授权。发现请求不携带 Bearer；客户端先以二维码固定的 TLS SPKI 建立通道，再核对服务身份、随机 challenge、签名及 manifest 版本/修订号。只有通过这些检查的签名 manifest 才能更新受管候选地址。NSD 解析出的临时地址不能自行进入正式线路列表，身份响应也不能扩充候选。

签名 manifest 只管理同实例的最多六个地址。`managed:true` 地址在手机始终只读，关闭自动同步也不能编辑其 `source` 或 `tls`。手机新增额外地址固定为 `managed:false,source:manual,tls:system`，不会借此获得 pin 或绕过电脑登记。地址变化不更换逻辑配对身份，不清草稿，不自动重发写入。旧二维码不会从未经授权的网络响应自行升级自动发现；需在新版电脑重新扫码一次。

自动发现受 Wi-Fi 隔离、组播可达性、操作系统后台限制及实际路由影响，不能保证任何网络必达。已有可信地址均失效时的恢复和实体 Wi-Fi 场景以 VALIDATION.md 的实际验收范围为准。

## App 0.3.1 ADB文件边界

固定App专属外部目录仅作inbox/outbox/media交换面；Android Keystore和私有设备凭据不搬到外部目录。DUMP保护显式广播命令入口，普通App不能以Intent payload生成私有pending任务；MainActivity只读内部已登记的一次性条目。严格英文basename、nofollow文件读取、有界类型/长度/图片尺寸，拒绝路径穿越；先atomic私有stage+history再消费入口。失败初始输入保留；processing中断标delivery_unknown不自动重复准备。

prepared仅表示配对预览或本地图片草稿，不触发claim/send/answer或自动允许。台账有界、显式维护递增epoch，旧ID拒绝；没有在途任务才允许维护。outbox仅脱敏状态/错误码/计数，不能用此入口备份密钥。外部目录在旧Android或特定厂商上的保护依赖平台，配对票据仍应只短时使用，电脑原文件也需自行保管。

## 0.4.0 配置邀请与网卡选择

可复用配置链接不包含设备 token/ticket，不授予聊天读取、发送或审批权限。它提供公开服务身份、固定 TLS SPKI、配置 ID 和少量 HTTPS+pinned 种子。预览纯本地；用户明确点“导入并连接”才联网，同已配对服务只刷新已验证地址，新服务领取短期票据并沿原流程在电脑核对短语批准。服务名称可伪装，必须核对身份指纹；同名不同 pin 仍视为另一服务。旧 App 需升级才支持此入口。

配置与配对签名域分离，签原始 payload 并绑定 challenge、服务身份、配置 ID、版本、revision；配对结果还带有效期。随机 nonce 不授予替换 pin 或接受任意地址的权力。轮换拒绝旧配置链接的 issued/pending 票据，不撤销 approved 设备。邀请仍可能带来待确认请求，具有请求和数量上限；不要将邀请误当登录凭据或设备撤销替代品。

原生导入有独立取消代次与请求范围；关闭时同时取消网络、未提交候选和 JS 配对状态，避免迟到响应更新线路或留下隐藏候选。旧有效 grant 直到新配对 commit 前保留，取消不注销原设备。深链/扫码在导入或配对在途时不会覆盖当前操作。URI fragment、完整 payload、票据和私钥不得记录日志。

网卡排除仅针对指定本机接口，如电脑专用直连 eno2；不封禁整个 10/8 地址范围。界面显示实际 active_url，内部逻辑 URL 不能作为当前连接线路证据。0.4 实体安装、光学扫码、移动数据和后台送达能力按 VALIDATION.md 实际范围报告。
