# 0.4.0 可复用服务配置链接

电脑管理页“手机连接配置”可生成配置链接与二维码。链接使用 `codexpocket://import#v1.<base64url JSON>`，可重复使用，没有两分钟到期限制；它是寻找服务并申请配对的邀请，不是设备访问授权。不要把它当作登录令牌，也不建议公开传播，以免增加待确认请求。

## 手机怎么用

1. 升级到 App 0.4.0；旧 App 不支持此导入入口。保留原有安装和私有数据，同签名覆盖升级，避免卸载丢失本地内容。
2. 扫描配置二维码、点击配置链接，或在设置“导入或更换服务”粘贴链接。App 先本地预览服务名称、地址、短服务身份与 TLS 指纹，不在预览阶段联网、申请或批准。
3. 对照电脑页指纹。名称只是标签；同名但身份不同仍是另一台电脑。确认后点“导入并连接”。
4. 若是已配对的同一服务，只验证并更新地址，保留设备凭据、总控和草稿。若为首次连接或另一台服务，App 领取短期票据并请求配对；仍须在电脑管理页核对手机短语并批准，之后才获得独立设备凭据。

导入或配对进行中不会被新链接覆盖。取消会立即取消原生请求和未提交候选，并清除本次手机候选；原有效配对保留。网络失败保留明确提示，不自动批准、不自动发送聊天或审批。旧版一次性 JSON/二维码入口保留在电脑页兼容折叠中。

## 电脑管理与轮换

配置链接可以再次复制，无需每次生成短期二维码。链接内的种子可能随时间变旧；只要仍有一个种子可验证，手机可获取签名清单。全部失效且没有可用恢复入口时，应重新获取当前配置链接或恢复网络，不能保证跨任意网络找到电脑。

点“轮换链接”后，旧链接及其尚未完成的 issued/pending 票据失效；已经批准的设备不受影响。要撤销设备访问，仍需使用设备管理中的撤销。旧配置 ID 不能当 Bearer 访问聊天或发送消息。

## 信任与边界

链接只含公开服务身份、TLS SPKI、配置 ID、名称和最多三个 HTTPS+pinned 种子，不含设备 token 或配对 ticket。明确导入后才向服务请求 nonce 绑定的签名结果；新设备配对结果包含短期 ticket、有效期、配置 ID 与地址版本，使用独立签名域。服务最多发布六条地址，原有 HTTPS、身份核验和写入未知不重放规则继续生效。

配置链接不创建 VPN，不修改防火墙；手机仍需要可达的局域网、Tailscale 或其他已配置网络。0.4 实体手机升级安装、相机光学扫码、点击外部链接和移动数据路径尚待实测；受控界面检查不替代这些验收，最新状态见 [验证记录](VALIDATION.md)。
