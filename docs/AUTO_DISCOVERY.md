# 0.4.0 自动发现与配置导入

## 现在怎样用

电脑启动服务后，自动读取本机局域网地址及 Tailscale 自身地址/稳定名称。管理页生成可复用配置链接/二维码，无需先填局域网IP。手机先预览、明确导入，首次连接在电脑允许后，默认开启地址自动同步和自动选路。公网等其他地址仍可选手动添加。

电脑约每15秒重新检查地址；变化时先启动新地址上的加密监听，成功后更新签名地址清单和局域网公告，再撤回旧监听。手机收到版本提示、回到前台、网络变化或定期检测时合并同步；改变地址不改变配对身份、草稿或投递编号。手动固定的目标消失时明确不可用，不擅自改成别的固定目标。

默认旧API仍为127.0.0.1:32848，管理仍为127.0.0.1:32849。新增32851为自动发现专用TLS端口，只绑定检测到的本机可信私网/Tailscale地址，另有本机诊断监听；不自动开启公网转发、UPnP、防火墙或Tailscale登录。`--tls-port`可处理端口占用，`--no-discovery`保留旧手动模式。

## 扫码一次为什么能跟随地址变化

二维码固定两项：服务签名身份、独立加密连接公钥指纹。自动地址使用固定指纹TLS；手机精确核对叶证书公钥和有效期，变化的局域网IP无需你自行申请域名证书。普通公网线路继续使用系统CA与主机名校验；特殊pin不会进入系统证书库或其他网络请求。

手机获取随机挑战签名的地址清单，检查原始payload签名、服务身份、TLS指纹和持久化版本。清单中新增地址还要完成该地址的TLS及身份验证，才能发送设备凭据。清单只同步电脑管理的地址，手机本地手动项目保持；总数超过6条时明确拒绝，不悄悄覆盖。自动地址及其安全属性不可由手机编辑降级。

电脑私有目录新增server-tls-key.pem与server-tls-cert.pem，另保留server-identity.pem及原数据库。私钥和数据库须共同备份。证书每日检查，接近到期时沿用同一密钥续证并重载，因此指纹不变。删除身份文件或恢复分叉数据库可能需要重新配对；不支持复制密钥后的多主服务。

## 所有旧地址都不通时

同一局域网内，手机通过Android NSD寻找`_codexpocket._tcp.`公告，服务名称和TXT只是线索。候选必须先通过原二维码的TLS指纹和签名清单核验，不会收到设备Bearer。NSD只作临时寻找入口，不把发现者IP自行加入可信地址。发现窗口和候选数量有上限，无定位/SSID读取，也不扫描整段网段。

跨网时优先保留Tailscale稳定名称和可选公网入口作为种子。Tailscale本身须在需要的设备上可用；App不替你打开VPN或修改账号/ACL。mDNS不跨子网，路由器访客隔离、企业Wi-Fi过滤或模拟器NAT可能阻断它。如果所有旧种子都失效且没有可用的同LAN公告/稳定入口，手机会保留配对并提示网络条件，而不能凭空在互联网上找到电脑。

## 初次二维码里的主入口已经失效

扫码后先对二维码明示的多个种子做无凭据验证，再向通过的入口发起一次配对。主入口不可达或证书不符，不需要本人先选择LAN还是Tailscale。配对请求结果不明时不会跨地址盲目重发；已配对后的消息、审批和上传也保留既有“不自动重放”约束。

## 验证范围

实际本机读取到LAN和Tailscale自身投影，真实本机mDNS广播/查询解析成功；Android模拟器已完成无手填QR、坏TLS/失效首入口候选替代、真实私网TLS配对、签名清单补全、无重扫码的多次地址迁移、原配对与草稿保留，详见VALIDATION.md。

电脑本机多播查询不等于实体手机同LAN发现已验。AVD的NAT环境在所有已知入口失效时没有收到宿主机公告；该边界有保留记录，未伪称成功。真实家庭路由器到实体Android的NSD联调、漫游/省电/公网端口可达性尚待对应环境验回。

依据：[Android NSD官方指南](https://developer.android.com/develop/connectivity/wifi/use-nsd)、[Tailscale CLI官方说明](https://tailscale.com/kb/1080/cli)、[python-zeroconf原仓](https://github.com/python-zeroconf/python-zeroconf)。采用标准TLS/签名/发现API，没有用发现结果取代身份授权。

## 选择供手机使用的网卡

管理页“选择供手机使用的网络”显示检测到的接口及地址。取消电脑专用有线直连接口（例如本机 eno2）后，服务停止该自动 TLS 监听、撤回公告并从签名清单移除其地址；原手动配置保留，但同一被排除的本机 IP 不再发布。重新启用可恢复。选择持久保存，CLI `--exclude-interface` 可显式设置；未提供该参数时沿用保存值。

排除依据是网卡，不是地址前缀。其他供手机使用的网卡即使地址为 10.x 仍可发布，不存在一刀切禁止 10/8 的规则。手机设置显示实际活动线路或友好连接状态，内部逻辑配对 URL 仅作身份/缓存键，不能把旧逻辑地址误当当前路线。

新版配置邀请与首次电脑授权流程见 [配置导入](CONFIG_IMPORT.md)。0.4 在实体手机上的安装升级、光学扫码及移动数据尚未验；此前0.3实体同Wi-Fi配对和AVD证据仅保留原版本范围。
