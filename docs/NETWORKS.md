# 0.3.0默认自动发现

新版不再要求逐个登记LAN/Tailscale：电脑自动收集并签名发布，手机一次扫码后同步。公网额外地址可选，详见[AUTO_DISCOVERY.md](AUTO_DISCOVERY.md)。下面保留0.2手动线路的原理与兼容范围；0.3托管地址只读，自动私网使用QR固定指纹TLS。

# 多网络线路（0.2.0）

同一台电脑可以登记局域网、内网、Tailscale和公网的多个地址。它们必须通向同一个服务实例和数据库。客户端选择地址，不创建VPN、不打开路由器端口、不实施带宽聚合，也无法从HTTP响应判断Tailscale内部走直连还是DERP。

## 成熟做法与本次取舍

- [Home Assistant Companion](https://companion.home-assistant.io/docs/troubleshooting/networking/)支持内外网URL，其Wi-Fi SSID识别涉及系统位置权限。本App改用有限、真实服务响应检测，不读取SSID或要求定位权限。
- [Syncthing](https://docs.syncthing.net/users/relaying.html)在直连失败时使用中继，并会尝试恢复直连。这里借鉴“可用路径先服务、条件改善后再升级”的原则，不引入其同步协议或公开中继。
- [Tailscale](https://tailscale.com/kb/1257/connection-types)将设备身份和多种连接路径分开。这里只选择用户配置的HTTP服务地址，Tailscale本身继续负责其VPN与直连/中继协商，不复制或替代WireGuard。

以上于2026-10-26回读官方正文或原仓正文，属于设计参考，不是已对这些产品做性能对比。

## 配置路径

1. 电脑本机管理页“网络与线路”登记最多6个完整服务根地址；名称可写家里局域网、Tailscale、内网或公网。保存后，仅登记地址可获得该服务的身份检测签名。
2. 生成新的配对二维码，手机会一起获得候选地址和服务公钥。旧配对仍可按原单地址使用，启用自动多线路需要重新扫码。
3. 手机设置→网络与线路选择自动，或者手动固定某一条。已有手机新增地址时，先在电脑登记，再在手机添加并检测。
4. 线路不可达、未登记或身份不符会分别显示；不会因为一个地址返回了“在线”就向它发送手机凭据。

正式HTTPS示意：局域网可使用具备有效证书的内部域名或分流DNS，Tailscale可使用配置好的tailnet HTTPS域名，公网可使用自己的HTTPS反向代理。地址分类只是本人设置的标签，不代表测到了物理网络拓扑。

## 身份与失败边界

电脑私有目录新增server-identity.pem。二维码固定其P256公钥；无凭据挑战签名同时绑定随机nonce和完整origin（协议/主机/端口）。服务只为本机管理员已登记的origin签名。客户端必须独立验证候选origin、公钥摘要、随机数和签名，再允许凭据请求。网络响应不能自行添加新候选。

签名挑战不加密HTTP链路，也不单独防止明文实时中间人。正式版本只允许正常系统CA校验的HTTPS；开发版仅在本人显式允许的可信数字私网内使用HTTP。自动模式配置有HTTPS地址时不降级到HTTP；调试HTTP的人工固定由本人明确选择。所有请求拒绝跨地址重定向，没有“忽略证书错误”入口。

服务身份文件需与原数据库一起备份。把同一身份密钥复制到两套不同数据库，不构成容灾集群：投递账目会分叉，可能重复执行。本版不支持多主实例。

自动切路保持同一逻辑服务及设备身份，消息草稿不随地址变化清空。状态和图片GET在真实传输失败时可在验证的新线路上有限重试；普通500等服务错误直接显示，不因服务错误切线；消息、审批、上传和DELETE不自动重试。若电脑已接收消息而回执丢失，保留原编号与未知状态；换路不能把它当成一次新发送。

## 如何理解延迟

显示的是到服务的实际小型HTTP身份检测总耗时（含连接、服务响应和本机签名核验），不是ICMP ping、带宽测速或模型首字时间。自动选择以这些可观察数据和线路稳定性为依据，避免单次抖动引起频繁切换。图片吞吐、弱网和实体手机省电效果仍需在对应网络上实测，不根据线路名称编造速度。

原生前台30秒、可见后台服务运行期间120秒发起合并检测，最多3条并发/6候选；单项连接与读取超时各1.8秒，每轮约4.5秒上限。EWMA平滑后另一条需至少快20%且快40ms，经过20秒稳定期并连续两轮确认才健康升级；当前不可用或安全规则排除时不受健康升级等待影响。SSE的429/5xx只退避重连（上限15秒），不把应用限制误判为网络故障。实测证据见app/android/NATIVE-VALIDATION.md与docs/VALIDATION.md。没有运行可见后台连接时，不承诺App被系统停止后继续探测或送达提醒。
